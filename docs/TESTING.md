# Тестирование

Автотестов PlatformIO в проекте нет. Проверка — плата + Serial 115200 + сайт.

## Железо

- Карта GPIO из README, общий GND, 3,3 В на DESPI-C02.
- Полное обновление 20–30 с; не отключайте питание на середине refresh.
- Нет датчика: в логе `Optional BME/BMP280 not detected` — кадр погоды всё равно должен прийти.
- VIN датчика с D13 часто не тянет модуль: перенос на 3V3, затем `I2C scan: 0x76` или `0x77`.

## Сеть и кадр

| Наблюдение | Смысл |
|---|---|
| HTTP 404 | slug заменили на сайте |
| Unexpected PNG dimensions | сервер не 800×480 |
| Screen unchanged (ETag) | кеш включён, погода та же |
| PNG decode error | обрыв или файл &gt; 64 КиБ (например RGB-режим на сайте) |

Сверьте кадр в браузере (`Открыть PNG`) с тем, что на стекле после Reset. Датчик на сайте — демо; на стекле — query платы.
